# Mission 5 - Number Systems and Data

## 1. Objective

To understand decimal, binary and hexadecimal number systems.

## 2. Number Conversions

I practised converting numbers between decimal, binary and hexadecimal.

- 13 (Decimal) = 1101 (Binary)
- 25 (Decimal) = 11001 (Binary)
- 1010 (Binary) = 10 (Decimal)
- 1101 (Binary) = 13 (Decimal)
- A (Hexadecimal) = 10 (Decimal)
- 1F (Hexadecimal) = 31 (Decimal)
- 1111 (Binary) = F (Hexadecimal)

## 3. Python Program

I created a Python program to convert decimal numbers into binary and hexadecimal.

I tested it with 10, 25 and 100.

## 4. ASCII and UTF-8

ASCII represents characters using numbers. For example, A is 65 and a is 97. UTF-8 is a character encoding system that supports many languages.
