## My Learning

- I learned the basic working of a computer through the IPOS cycle.
- I practised Terminal commands to manage files and folders.
- I understood operating systems and file permissions.
- I wrote and executed basic Python programs.
- I learned decimal, binary and hexadecimal conversions.
- I practised Git and GitHub for version control.
- I explored basic networking concepts and how websites work.
