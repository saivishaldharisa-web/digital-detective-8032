## Work Completed

In this mission, I learned how Git tracks changes and how GitHub stores projects online.

### Git Commands

| Command | Purpose |
|---|---|
| `git status` | Checks the current status of files |
| `git add .` | Stages changes |
| `git commit` | Saves changes in Git history |
| `git log` | Displays previous commits |
| `git push` | Uploads commits to GitHub |
| `git pull` | Downloads and integrates remote changes |
| `git branch` | Lists branches |
| `git switch` | Switches between branches |
| `git fetch` | Downloads remote updates |

### Branching

### Pull Request

After pushing the changes, I created a Pull Request from `update-about` to `main`.

### Git Glossary

- **Repository:** A place where project files and their history are stored.
- **Commit:** A saved version of changes.
- **Branch:** A separate line of development.
- **Remote:** A repository hosted online.
- **Push:** Uploading local commits.
- **Pull Request:** A request to review and merge changes.
