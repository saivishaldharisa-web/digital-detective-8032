## Commands Used

| Command | Purpose |
|---|---|
| `mkdir` | Creates folders |
| `mkdir -p` | Creates nested folders |
| `touch` | Creates files |
| `ls` | Lists files and folders |
| `git init` | Initialises Git |
| `git add .` | Stages changes |
| `git commit` | Saves changes |
| `git push` | Uploads changes to GitHub |
