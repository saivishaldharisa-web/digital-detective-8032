### Compiler and Interpreter

| Compiler | Interpreter |
|---|---|
| Translates the program before execution | Executes instructions while interpreting the program |
| Usually creates compiled output | Usually runs the program directly |
| Example: C | Example: Python |

### Difference in My Own Words

A compiler translates the program before it runs. An interpreter executes the program by interpreting its instructions. Both are used to run programs, but their working methods are different.
