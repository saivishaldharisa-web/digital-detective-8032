# Mission 4 - Programs

## 1. Objective

The aim of this mission was to learn how programs work and how to run a simple Python program.

## 2. Practical Work

I created a file called `hello.py` and wrote a simple print statement in it.

**Output:** Hello from Python

## 3. Compiler and Interpreter

- **Compiler:** Converts the whole program before running it.
- **Interpreter:** Runs the program by interpreting its instructions.

## 4. What I Learned

I learned how to write a basic Python program and run it using Terminal. I also understood the basic difference between a compiler and an interpreter.
